# Build Log — Curiosity Loop

Format per entry: what I tried · what broke · what I asked Claude · what finally worked.

## 2026-09-28 — Scaffold
- **Tried:** Planned the six-stage loop (Awareness → Reveal → Focus → Distortion → Forget → Orbit) with Claude.
- **Decisions:**
  - Webcam + MediaPipe (hands + pose). A webcam has no depth, so "distance" is estimated from shoulder width (body) and palm size (hand zoom).
  - Pointing = index finger extended with other fingers curled, plus a dwell timer. The grid freezes while pointing so users can aim.
  - One raised hand held for 1.5 s also reveals the grid, in case a stranger only lifts one hand.
  - Orbit adds visual trails so it looks noticeably different from Awareness ("the mirror remembers you").
  - The whole network is generated by `td/build.py`, so it lives in git even though the `.toe` doesn't.
- **What broke:** MediaPipe's .tox files are stored in Git LFS, so exact channel names couldn't be read ahead of time. The fix was a channel parser that auto-detects names, plus `Diagnose()`.
- **Next:** Install MediaPipe, run Diagnose, calibrate in the classroom.

## 2026-09-28 - First run in TouchDesigner (via Claude + TouchDesigner MCP)
- **Tried:** Ran `td/build.py` in TD 2025.33230 and drove every stage with the Simulate sliders.
- **What broke, and the fixes:**
  - TD's Python reads files as ASCII, so em dashes in the .py files crashed the build one-liner. Made all .py files ASCII and added `encoding='utf-8'` to the one-liner.
  - The photos rendered as flat color blocks. The Rectangle SOP `texture` parameter is a menu (`off`/`face`), not a toggle, so `True` left it off. Changed it to `'face'`.
  - A black dot appeared on the focused photo: the fading hand cursor still wrote depth and hid the photo behind it. Turned off depth test and depth writing on the cursor material, and set `drawpriority=-1` so cursors draw last.
  - Panning in Distortion slid the image off-screen. The pan is now clamped to the image edges, and the minimum zoom is 1x.
  - Code edits didn't take effect live: TD reloads a DAT module in place (same object), so the loop now detects changes by hashing the source text.
  - Open-hand hover selected photos by accident when hands were held still. It now defaults to off, so only pointing selects.
- **What worked:** All six stages: Awareness, Reveal (grid tilts with the hands), Focus (pointing charges the photo), Distortion (zoom about 2x, pan, velocity warp), Forget, and Orbit (strong lean and trails).
- **Open issue:** Loading `MediaPipe.tox` broke the MCP bridge's routes ("No route matched"). Restarting TD should fix it.
